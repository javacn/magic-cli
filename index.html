特色功能

features
📄

网页剪藏

一键把网页（公众号文章、知乎、新闻等）渲染为 Markdown，保存到本地或飞书云文档。

🎬

视频一键成笔记

粘贴视频链接即自动完成「下载 → 语音转写 → 场景抽帧 → 画面理解 → AI 生成结构化笔记 → 保存」全流程，支持 YouTube、Bilibili、Twitter/X 等 yt-dlp 支持的所有平台。

📚

合集 / 播放列表 / 多 P

支持 B 站空间合集、B 站多 P 视频、YouTube 播放列表，整部合集自动批量处理并归入统一文件夹。

🔍

聚合搜索

同时搜索 B 站视频与微信公众号文章，结果合并展示，并支持一键入队。

🗂️

队列管理

后台任务队列，限并发、断点续跑，失败自动重试。

💬

飞书进度卡片

处理过程实时推送飞书卡片，分阶段展示进度（下载 / 转写 / 抽帧 / 画面 / 生成 / 保存）。

⚙️

安装后配置

6 steps

配置统一保存在 ~/.magic-wiki/config.json，首次运行任一命令时自动创建，敏感字段展示时自动脱敏。

1
运行初始化向导（推荐）

magic-wiki init 是 v1.0.4 新增的交互式配置向导，引导依次填写飞书凭证、笔记保存根目录与通知目标，回车保留当前值 / 跳过。

$ magic-wiki init
2
查看配置文件位置

确认配置文件路径（默认 ~/.magic-wiki/config.json）。

$ magic-wiki config path
3
配置 LLM 模型（最重要）

笔记生成 / 视频分析 / 视觉理解都通过 OpenAI 兼容 API 调用大模型，需配置 llm.providers 与默认模型、备选链（模型 ID 格式 供应商/模型名；视觉模型需 input 含 "image"；失败自动沿 fallback 链切换熔断）。

$ magic-wiki config set llm.default_model "minimax/MiniMax-M3"
4
配置飞书凭证

剪藏到飞书 / 搜索发送汇总卡片时需要，在飞书开放平台创建自建应用后写入 App ID / App Secret。

$ magic-wiki config set feishu.app_id "cli_xxx"
5
可选配置

飞书知识库节点 feishu.wiki_node、通知目标 video_note.notify_target、笔记保存根目录 raw_dir、并发数、转写引擎、视觉 / 文本模型优先级链等。

6
验证配置

敏感字段自动脱敏，可按点路径读写。

$ magic-wiki config show

copilot-ready

以下提示词可直接整体复制给任意 AI 助手（Trae / Claude / GPT 等），让它在你的电脑上自动完成 magic-wiki 的安装与配置：

agent-install-prompt.txt
$ 你是一名终端助手。请在用户电脑上安装并配置 magic-wiki（magic-cli 系列的命令行工具，用于网页剪藏、B 站 + 公众号搜索与队列管理）。 步骤： 1. 安装：执行 npm install -g @magicstock/magic-wiki（国内网络慢时追加 --registry=https://registry.npmmirror.com） 2. 验证：执行 magic-wiki --version，确认输出版本号 3. 查看配置：执行 magic-wiki config path，确认配置文件位置（默认 ~/.magic-wiki/config.json） 4. 配置飞书凭证（用于剪藏到飞书、搜索发送汇总卡片；用户不需要飞书则跳过）： - 推荐：运行 magic-wiki init，按交互式向导填写 App ID / App Secret 等 - 或手动：magic-wiki config set feishu.app_id "..."，magic-wiki config set feishu.app_secret "..." 5. 可选配置（按用户需要执行）： - magic-wiki config set feishu.wiki_node "..." # 保存到飞书知识库 - magic-wiki config set video_note.notify_target "..." # 飞书通知目标 - magic-wiki config set raw_dir "~/notes" # 笔记保存根目录（默认 ~/.magic-wiki/wiki） 6. 验证配置：执行 magic-wiki config show（敏感字段自动脱敏） 7. 功能自测：执行 magic-wiki search "测试" --limit 3 完成后向用户汇报：安装版本、配置文件路径、已配置的配置项。

快速开始

quickstart
terminal — zsh
$ magic-wiki init # 首次使用：交互式初始化配置 $ magic-wiki clip https://mp.weixin.qq.com/s/xxx # 剪藏网页（默认 markdown） $ magic-wiki clip https://xxx --target feishu --title "我的笔记" $ magic-wiki search "AI 短剧" # 搜索 B 站 + 公众号 $ magic-wiki queue status / start / stop / clean --days 14 $ magic-wiki enqueue https://www.bilibili.com/video/BVxxx # 视频一键成笔记（入队） $ magic-wiki enqueue https://space.bilibili.com/xxx/lists/xxx # 合集 / 播放列表 / 多 P $ magic-wiki config show # 配置（敏感字段脱敏）

magic-wiki init交互式初始化配置向导
magic-wiki config <action>配置管理（show/path/env/get/set/unset）
